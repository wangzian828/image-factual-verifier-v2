# `perceive_scene` 恢复修复与真实 smoke 记录

日期：2026 年 9 月 2 日

## 问题

当前 smoke 使用 `gemini-3.1-pro-preview` 时，10 条轨迹中有 3 次
`perceive_scene` 工具错误：

- 2 次 Gemini HTTP 400：`invalid_request`；
- 1 次在 150 秒工具边界内超时。

这些错误被记录在轨迹中，没有伪装成成功观察，但会让视觉记忆缺失。

## 修复

- 视觉工具默认使用受控 JPEG，而不是把原始大图直接转成 base64；
- Gemini 视觉 structured-output 请求使用 API 兼容 schema 投影，移除
  `maxLength`、`maxItems` 等 provider 不需要的校验约束；
- `perceive_scene` 对可恢复的 400、传输失败和超时最多追加一次恢复请求：
  使用更小的压缩图和宽松对象 schema；
- 成功恢复时写入 `perception_attempts` 与 `perception_recovery`；
  两次都失败时仍返回 `status=error`；
- active ReAct 工具动作默认保留 210 秒边界，为一次恢复和清理留出空间。

成熟工具的公开名称、任务语义和本地输出归一化契约没有改变。

## 逐条轨迹问题清单

以下是本轮只读审阅结果，暂不在本轮继续修改 Agent：

### Gemini 3.1 Pro Preview

- `main-02727`：最终依据为空，却在 `check_consistency` 429 后用“人物没有地面反射”
  直接判 fake；这是视觉异常推断，且没有进入有效证据账本。
- `main-02728`：虽然判断命中 gold，但把解剖异常、阴影和“AI-generated”作为主要理由；
  反向搜图失败后仍继续使用大量泛化视觉异常。
- `main-02729`：只有 3 个动作，主要依据阴影方向不一致就结束，缺少对图片所表达事实的
  外部核查，属于需要重点复核的短轨迹。
- `main-02730`：搜索为空后仍能通过一次页面访问得到支持；结果可用，但应检查空搜索结果
  是否被模型正确理解为“没有结果”。
- `main-02731`：视觉感知、OCR、页面访问链路完整，判断命中；调查仍较短，但目前没有明显
  工程问题。
- `main-02732`：反向搜图后访问到原始发布说明“摄影合成与编辑”，判断依据较直接。
- `main-02733`：判断命中，但页面验证码导致没有验证证据；严格审计发现事实核查导向的
  query 泄漏，共 7 个重复记录，需后续单独处理。
- `main-02754`：把重复姓名牌和伪文字当成 fake 依据，实际 gold 为 real，属于明显的
  AI/视觉异常误判。
- `main-02755`：把乱码、疑似生成痕迹和与 JWST 图片不相似当成 fake 依据，实际 gold 为
  real，属于同类视觉异常误判。
- `main-02756`：在注意到视觉异常后仍输出 real，理由边界相对符合当前规则。

### Gemini 3.7 Flash

- `main-02727`：把“反射和解剖看起来协调”当成真实性依据，实际 gold 为 fake；这是
  以没有发现视觉异常替代事实核查。
- `main-02728`：实际 gold 为 fake，却以“没有合成痕迹、物理关系自然”判 real；另有一次
  反向搜图上传失败。
- `main-02729`：实际 gold 为 fake，却根据地点元素和光影协调判 real，未闭合图片表达的
  具体事实。
- `main-02730`：实际 gold 为 real，却根据现场轨道/接触网的推断判 fake；需要复核是否
  把时间状态或未被来源支持的现场细节扩大成了反证。
- `main-02731`：3 个动作即结束且证据账本为空，虽命中 gold，调查深度不足。
- `main-02732`：反向搜图/文本/局部视觉链路共同支持合成判断，当前较合理。
- `main-02733`：判断命中，但访问被验证码拦截；报告仍引用未验证的事实核查线索，
  证据质量不足。
- `main-02754`：重复姓名牌、伪文字等视觉异常导致 real case 被判 fake。
- `main-02755`：乱码和“AI generation”痕迹导致 real case 被判 fake。
- `main-02756`：多步视觉和页面检查后判 real，当前没有工程错误。

共同结论：本次 `perceive_scene` 修复解决的是“视觉工具请求失败”问题，
没有解决 ReAct 的调查质量问题。后续最需要处理的是视觉异常工具的语义边界、
搜索无结果/外部不可用后的收尾条件，以及 3.7 对支持/反驳事实的判断偏差。
