## 三、能力格子详细分布

能力格子使用 manifest 中的 `target_capability_cell` 字段。当前有 12 个非空格子：
`AF1`–`AF4`、`CD1`–`CD4`、`EF1`–`EF4`；定义在下表中完整保留。

### 能力格子代号的含义

前缀表示造假所属的大类：

| 前缀 | 英文全称 | 中文含义 | 人话解释 |
| --- | --- | --- | --- |
| `AF` | Attribute Forgery | 属性伪造 | 对真实对象或场景的关键属性做了篡改 |
| `CD` | Context Displacement | 语境错置 | 图片本身可能真实，但被放到了错误的时间、地点或平台语境中 |
| `EF` | Existence Fabrication | 存在性捏造 | 声称某个主体、关系、事件或现象存在，但实际并不存在或没有发生 |

具体格子含义如下：

| 代号 | 中文名称 | 含义 |
| --- | --- | --- |
| `AF1` | 数字/统计篡改 | 图片中的数字、年限、比分、排名或其他统计信息被改动。 |
| `AF2` | 人物/机构身份错标 | 真实人物、机构或标识被错误归属给另一个人物或机构。 |
| `AF3` | 时空属性错误 | 真实建筑、地标或物体的位置、形态、结构等属性与真实情况不符。 |
| `AF4` | 文字/标志替换 | 图片中的铭文、文字、Logo、旗帜、公式等符号信息被替换或篡改。 |
| `CD1` | 时间戳伪造 | 图片中的日期或时间戳是伪造的，或与图片内容、事件时间线矛盾。 |
| `CD2` | 旧图新用 | 真实的历史图片被拿来声称是当前或另一件新事件的现场。 |
| `CD3` | 平台/账号伪造 | 社交媒体或官方机构截图中的账号、认证标识、平台界面或来源被伪造。 |
| `CD4` | 地理线索错置 | 图片中的路牌、语言、建筑风格等地理线索与声称发生地点不一致。 |
| `EF1` | 主体行为捏造 | 真实人物或机构被捏造成做过某个行为、发布过某项内容或参与过某个事件。 |
| `EF2` | 主体关联捏造 | 两个或多个真实人物、机构被捏造成存在并不存在的会面、合作、冲突或隶属关系。 |
| `EF3` | 事件/现象无依据 | 图片声称某个事件或现象存在，但它违背常识/物理规律，或没有可信记录支持。 |
| `EF4` | 合成主体捏造 | AI 生成的人物、场景或事件被包装成真实存在的主体或真实发生的事情。 |

能力格子合计校验：

```text
非空格子：5,884 = 4,982 train + 902 test
未标注格子：4,290 = 3,508 train + 782 test
5,884 + 4,290 = 10,174
```

能力格子与测试集的关系：测试集 1,684 条中，902 条属于 12 个能力格子，782 条没有
`target_capability_cell`。因此不能把 1,684 条测试集简单理解为 12 个格子各自的均匀
测试样本；支持类和网页图路线主要位于未标注格子部分。

## 六、使用边界

- `train-manifest.jsonl` 是当前教师 rollout 的唯一输入；
- `test-manifest.jsonl` 只能用于独立测试和 QA，不能混入教师轨迹、SFT 或 RL；
- runtime release 只向 Agent 暴露 `case_id`、图片路径和图片哈希等公开运行字段；
- private gold、标签、证据和数据构造元数据只能在 rollout 完成后用于 SFT 审计和分类；
- 原始归档、测试集原图备份和生图替换映射保持独立，不因训练集使用而删除。
